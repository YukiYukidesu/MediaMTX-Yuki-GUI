# 语言包目录

这里放界面文案。**加一种新语言不需要改一行代码**：往本目录丢一个 `xx-YY.json`，程序启动时会自动扫描到它。

## 文件命名

用 [BCP 47](https://www.rfc-editor.org/info/bcp47) 的语言标签，扩展名固定 `.json`：

| 文件名 | 语言 |
|---|---|
| `zh-CN.json` | 简体中文（基准语言） |
| `en-US.json` | 英语 |
| `ja-JP.json` | 日语 |
| `zh-TW.json` | 繁体中文 |

## 文件格式

一个扁平的键值对，值就是界面上显示的文字：

```json
{
  "_language_name": "日本語",
  "_translated": "false",
  "l001": "総覧",
  "l002": "すべての入力がどこへ配信されているかをひと目で確認",
  "l003": "実行中"
}
```

### 两个下划线开头的保留键

| 键 | 作用 |
|---|---|
| `_language_name` | 语言自己的名字，显示在「设置 → 界面语言」下拉里。不写就用文件名。 |
| `_translated` | 填 `"true"` 才会出现在下拉里。没翻完先填 `"false"`，别人就选不到它。 |

除了这两个，所有键都不以下划线开头，照着 `zh-CN.json` 抄就行。

## 怎么翻

1. 复制 `en-US.json` 成你需要的文件名，比如 `fr-FR.json`。
2. 把 `_language_name` 改成 `"Français"`，`_translated` 保持 `"false"`。
3. 逐条把右侧的 `""` 填上译文。
4. 全部填完把 `_translated` 改成 `"true"`。
5. 重启程序，在「设置 → 界面语言」里就能看到它。

## 规则

- **不要改动键名**（`l001`、`c020` 这些）。键名和界面对应关系是写死在程序里的，改了就对不上。
- **不要删键**。少一条会回退到中文，不会崩，但那条就还是中文。
- `{}`、`%s` 之类的占位符原样保留，别翻译。
- 值里可以含中文标点、换行（写成 `\n`），不要写未转义的双引号。
- 空字符串 `""` 表示「这条还没翻」，程序会自动回退到中文。

## 漏翻了会怎样

程序取文案的顺序是：**当前语言 → 中文 → 键名**。

所以漏翻的条目会显示中文，不会显示成空白或 `l123`。如果界面上真的冒出 `l123` 这种东西，说明中文包里也缺这条 —— 那是程序的问题，不是翻译的问题。

当前语言还差多少条，可以在「设置 → 界面语言」下面看到（`还差 N 条未翻译`）。
